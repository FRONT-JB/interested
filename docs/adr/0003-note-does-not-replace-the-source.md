# Note는 원문을 대체하지 않는다

Note 본문의 대부분은 Source에서 무엇을 얻었고, 어디에 쓸 수 있고, 어디가 미심쩍은지에 쓴다. 원문의 주장 자체는 짧게 가리키는 데 그친다.

세 가지 이유다. 순수 요약은 이미 흔해서 차별점이 없고, 남의 저작물을 대체할 분량으로 불특정 다수에게 발행하는 자리를 피하려는 것이며, Concept 그래프가 "내 관심의 궤적"이라는 의미를 가지려면 관점이 본문이어야 하기 때문이다.

## Consequences

요약이 얇은 것은 게으름이 아니라 방침이다. "요약을 더 충실히"는 개선이 아니라 이 결정의 철회이며, 그 경우 저작권상의 위치와 이 저장소의 차별점을 동시에 잃는다.
