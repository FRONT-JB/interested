# 관찰자는 관측 가능한 동사만 쓴다

Portrait과 Arc는 관찰자가 쓰는 문서다. 여기에는 기록으로 증명되는 동사만 쓴다.

- **허용** — 읽었다, 돌아왔다, 옮겨갔다, 조사하고 있다, 관심이 있다
- **금지** — 습득했다, 익혔다, 이해했다, 능숙하다

읽었다는 사실에서 관심은 따라 나오지만 습득은 따라 나오지 않는다. 실제로 익혔는지는 본인만 알고, 그걸 기계가 대신 말하면 문서 전체가 검증할 수 없는 것이 된다. 이 저장소의 이름이 `interested`인 것이 그대로 이 규칙이다.

성취를 말하고 싶으면 사람이 직접 문장을 넣는다. 그렇게 들어간 문장은 관찰자의 말이 아니라 본인의 말이다.

## Consequences

- **이 규칙이 자동화를 안전하게 만든다.** 관측 서술만 하는 문서는 사람 손 없이 자라도 거짓말을 하지 않는다. 그래서 저장소가 둘로 갈린다 — 손이 가는 것(Note, Trail)과 저절로 자라는 것(Portrait, Arc).
- 판정의 범위는 **집계된 사실과 사실끼리의 대비**까지다. "관심은 `rsc`인데 이번 주 커밋은 CSS였다"는 허용되고, 그 이상의 해석은 안 된다.
- 재료는 사람이 쓴 Note와 사람이 한 커밋뿐이다. 이 조건이 [ADR-0004](./0004-the-skill-does-not-invent-the-perspective.md)를 깨지 않고 관찰자를 도입할 수 있게 하는 유일한 근거이므로, 재료가 늘어날 때 이 ADR을 다시 읽을 것.
- GitHub 활동은 Portrait 안에서만 쓰이는 재료이고 이 저장소의 개념이 아니다. 별도 기록을 남기지 않으므로 API가 막혀도 마크다운 정본은 멀쩡하다.
