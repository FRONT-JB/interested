# Note는 Concept을 거쳐서만 이어진다

Note끼리 직접 엣지를 맺지 않는다. 모든 Note는 자신이 다루는 Concept을 참조하고, Note 사이의 관계는 공유 Concept을 통해 계산으로 도출한다.

## Considered Options

- **분류 태그만 둔다** — 유지비가 사실상 0이지만, Trail이 뽑을 수 있는 패턴이 "이번 주 AI 5개, 프론트엔드 3개" 수준으로 얕아진다.
- **Note 간 관계 그래프** — "이 영상은 저 글을 반박함" 같은 엣지는 표현력이 가장 높지만, 손으로 유지하는 비용이 Note 수의 제곱으로 커져 결국 방치된다.

## Consequences

- Note에 "관련 글" 링크가 없는 것은 누락이 아니라 의도다. 관련성은 Concept을 경유해 렌더링 시점에 계산한다.
- Concept 어휘가 흔들리면 그래프가 조각난다. 이름의 일관성이 이 구조의 단일 실패 지점이다.
